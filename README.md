# 🌎 AI Traveling Booking Platform

A comprehensive travel booking platform integrated with an AI-powered recommendation system to help users find their perfect destinations based on mood, budget, and preferences.

## 🚀 Overview

This platform consists of three main components working in harmony:
- **Frontend**: A modern, responsive React application.
- **Backend**: A robust Node.js & Express API with MongoDB.
- **AI Engine**: A Python-based ML service for smart recommendations.

---

## 🛠️ Tech Stack

### Frontend
- **Framework**: [React 18](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Bootstrap 5](https://getbootstrap.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Components**: [React Responsive Carousel](https://www.npmjs.com/package/react-responsive-carousel)

### Backend
- **Runtime**: [Node.js](https://nodejs.org/)
- **Framework**: [Express.js](https://expressjs.com/)
- **Database**: [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/)
- **Authentication**: [JSON Web Tokens (JWT)](https://jwt.io/) & [Bcrypt](https://www.npmjs.com/package/bcrypt)
- **Email Service**: [SendGrid](https://sendgrid.com/)

### AI Recommendation Engine
- **Language**: [Python 3.9+](https://www.python.org/)
- **ML/NLP**: [Scikit-learn](https://scikit-learn.org/), [NLTK](https://www.nltk.org/), [Sentence-Transformers](https://www.sbert.net/)
- **Data Analysis**: [Pandas](https://pandas.pydata.org/), [NumPy](https://numpy.org/)
- **API Framework**: [Flask](https://flask.palletsprojects.com/)
